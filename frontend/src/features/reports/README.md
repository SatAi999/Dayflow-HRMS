# Member 4 — Corporate Reports Module

This module provides enterprise-grade reporting and data analytics across Dayflow HRMS:

- **Reports Landing Center (`/admin/reports`)**: Grid of available reports based on role permissions.
- **Attendance Report (`/admin/reports/attendance`)**: Daily check-ins, hours, presence rates.
- **Leave Report (`/admin/reports/leave`)**: Leave categories, approval ratios, pending requests.
- **Payroll Summary Report (`/admin/reports/payroll`)**: Basic salary, deductions, net payouts.
- **Employee Directory Report (`/admin/reports/employees`)**: Headcount distribution and join dates.
- **Reusability**: Uses `FilterBar.jsx`, `Table.jsx`, `exportToCSV`, `printReport`.
